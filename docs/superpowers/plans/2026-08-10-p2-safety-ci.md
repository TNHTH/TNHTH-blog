# Plan 2：Safety + CI

## Goal

让公开快照、文本扫描、媒体扫描和 CI 的权限边界可验证。

## Prerequisites

- Plan 1 已完成，仓库只生成标准 Astro static output。

## Files

- `scripts/policy.ts`
- `scripts/validate-public.ts`
- `package.json`
- `.github/workflows/ci.yml`
- `tests/**`

## Tasks

1. 文本和媒体分流扫描，禁止二进制按 UTF-8 读取。
2. CI 使用 checkout/setup-node/pnpm-action v6，普通检查仅 `contents: read`。
3. 增加公共 manifest 字段审计和路径/secret/元数据负向测试。

## Tests First

- 文本扫描覆盖路径、token、邮箱、内部链接。
- 媒体扫描覆盖 GPS/EXIF/XMP/IPTC 与非媒体二进制。

## Implementation

扫描器按扩展名和文件集合路由；所有公开资产只允许脱敏 derivative。

## Acceptance Gate

`pnpm content:verify`、`pnpm privacy:text`、`pnpm privacy:media`、`pnpm audit:public`、`pnpm check`、`pnpm test`、`pnpm build` 全部通过。

## Rollback
